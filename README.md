# Content Work

这是一个用于内容工作流的本地项目仓库。

## 目录结构

- `sessions/`：保存按次或按阶段整理的工作会话记录、过程产物和复盘信息。
- `docs/`：保存项目说明、流程文档、研究资料和其他长期可复用的正式文档。
- `prompts/`：保存可复用的提示词、任务模板和提示词版本记录。

## 项目文档

- `AGENTS.md`：记录本项目中协作代理和自动化工具应遵守的工作规则。
- `PROJECT_STATUS.md`：记录当前项目状态、已完成事项、进行中事项和下一步计划。
- `DECISIONS.md`：记录重要决策、背景、取舍和决策日期。

## Git 约定

- 默认分支：`main`
- 远程仓库：`https://github.com/STANLEY-SUN/content-work.git`
- 提交应保持小而清晰，便于回溯内容工作过程。
